# [A2A协议与实现-10]利用MAF的A2AAgent作为远程调用Agent的代理

通过[A2A协议与实现-09:.NET SDK客户端的设计与实现](https://blog.csdn.net/jaydenai/article/details/163230398)的介绍，我们知道可以利用IA2AClient对象远程调用A2A Server，根据采用的协议不同，我们可以选择`A2AClient`和`A2AHttpJsonClient`。`A2AAgent`则提供一种更加方便的交互方式：将承载于A2A Server的远程Agent视为**本地Agent一样调用**。

## 1. 连接A2A Server创建A2AAgent

如下演示的是一个ASP.NET Core程序，我们通过调用`WebApplication`的扩展方法`MapA2AHttpJson`以`HTTP-JSON`协议，基于创建的`AIAgent`构建了一个A2A Server。启动之后，我们根据通信协议创建了对应的`A2AHttpJsonClient`客户端，并据此创建了`A2AAgent`。

```csharp
using A2A;
using Azure.AI.Projects;
using DotNetEnv;
using Microsoft.Agents.AI.A2A;
using Microsoft.Agents.AI.Hosting;
using Microsoft.Extensions.AI;
using OpenAI;
using OpenAI.Responses;
using System.ClientModel;

Env.Load();
var apiKey = Environment.GetEnvironmentVariable("OPENAI_API_KEY")!;
var endpoint = Environment.GetEnvironmentVariable("OPENAI_BASE_URL")!;

var agent = new OpenAIClient(
    credential: new ApiKeyCredential(key: apiKey),
    options: new OpenAIClientOptions { Endpoint = new Uri(endpoint) })
.GetResponsesClient()
.AsAIAgent(
    model: "gpt-5.4-mini", 
    name: "a2a-agent",
    instructions: """
    你是一个深谙中国古代历史的专家，善于根据正史，以公正客观的态度于人交流历史问题。
    对于用户提出的问题，请以简介概括性的语言予以答复，字数尽量保持在200字以内。
    """);

var buidler = WebApplication.CreateBuilder();
buidler.Services
    .AddA2AServer(agent.Name!)
    .AddAIAgent(agent.Name!, (services, anme) => agent)
   ;
var url = "http://localhost:3721/";
buidler.WebHost.UseUrls(url);
var app = buidler.Build();
app.MapA2AHttpJson(agent, "/");
await app.StartAsync();

using var client = new A2AHttpJsonClient(new Uri(url));
var a2aAgent = new A2AAgent(client);
var session = await a2aAgent.CreateSessionAsync();
while (true)
{
    Console.Write("\n$ (:q or quit to exit): ");
    var message = Console.ReadLine();
    if (message is ":q" or "quit")
    {
        break;
    }    
    await foreach (var update in a2aAgent.RunStreamingAsync(message!, session))
    {
        Console.Write(update);
    }
}
```

我们构建了一个循环，在同一个Session中利用`A2AAgent`作为代理，完成与远程Agent的对话。如下所示的就是我与AI进行的一段简单的针对齐鲁两个不同命运的交流。

## 2. A2AAgentSession

在正式介绍`A2AAgent`的实现原理之前，我们先介绍它的一些周边。首先介绍的是通过调用其`CreateSessionAsync`方法创建的`A2AAgentSession`。如下面的代码所示，`A2AAgentSession`继承自`AgentSession`。A2A语境下的Context其实就是Session的概念，所以`ContextId`和`SessionId`、`ThreadId`与`ConversationId`表达同一个概念。如果采用后台任务来处理Agent调用，后台任务的ID和状态分别通过`TaskId`和`TaskState`表示。

```csharp
public sealed class A2AAgentSession : AgentSession
{
	public string? ContextId { get; }
	public string? TaskId { get;  }
	public TaskState? TaskState { get; }
}

public enum TaskState
{
	Unspecified,
	Submitted,
	Working,
	Completed,
	Failed,
	Canceled,
	InputRequired,
	Rejected,
	AuthRequired
}
```

## 3. A2AContinuationToken

如果调用`A2AAgent`返回的`AgentResponse`携带一个`ResponseContinuationToken`，意味着Agent的执行尚未结束，还需要携带这个Token发起后续的调用。对于A2A来说，只有采用后台任务处理Agent调用请求才会出现这样的情况，所以这样的`ResponseContinuationToken`应该携带后台任务的信息。此Token对应的类型为`ResponseContinuationToken`，它利用`TaskId`返回尚未结束的后台任务的ID。

```csharp
internal class A2AContinuationToken : ResponseContinuationToken
{
    internal A2AContinuationToken(string taskId); 
    internal string TaskId { get; }
}
```

## 4. A2AAgent

由于`A2AAgent`使用`IA2AClient`对象远程调用A2A Server，所以我们在初始化`A2AAgent`对象时必须执行此对象。除此之外，我们可以采用如下两种方式（分别指定或者利用`A2AAgentOptions`配置选项）指定Agent的Id、名称和描述。

```csharp
public sealed class A2AAgent : AIAgent
{
    public A2AAgent(
        IA2AClient a2aClient, 
        string? id = null, 
        string? name = null, 
        string? description = null, 
        ILoggerFactory? loggerFactory = null);   
    public A2AAgent(
        IA2AClient a2aClient, 
        A2AAgentOptions options, 
        ILoggerFactory? loggerFactory = null);
}

public sealed class A2AAgentOptions
{
    public string? Id { get; set; }
    public string? Name { get; set; }
    public string? Description { get; set; }
}
```

## 4.1 阻塞式调用

在重写的`RunCoreAsync`方法中，如果指定的`AgentSession`为`null`，会创建一个空的`A2AAgentSession`对象。如果`AgentRunOptions`的`ContinuationToken`不为`null`，会采用如下的流程处理请求：

- 如果`ContinuationToken`类型不是`A2AContinuationToken`，则从中解析出`TaskId`并创建对应的`A2AContinuationToken`；
- 根据`TaskId`调用`IA2AClient`对象的`GetTaskAsync`方法得到描述后台任务的`AgentTask`象；
- 将`TaskId`和表示后台任务状态的`TaskState`写入当前的`A2AAgentSession`；
- 采用如下的方式根据`AgentTask`创建一个`AgentResponse`，并将其作为返回值。

```csharp
private AgentResponse ConvertToAgentResponse(AgentTask task)
{
    return new AgentResponse
    {
        AgentId = this.Id,
        ResponseId = task.Id,
        FinishReason = MapTaskStateToFinishReason(task.Status.State),
        RawRepresentation = task,
        Messages = task.ToChatMessages() ?? [],
        ContinuationToken = CreateContinuationToken(task.Id, task.Status.State),
        AdditionalProperties = task.Metadata?.ToAdditionalProperties(),
    };
}
```

否则会根据当前的`A2AAgentSession`、输入的消息列表和`AgentRunOptions`创建`SendMessageRequest`对象，具体的构建逻辑如下：

- 将传入的`ChatMessag`列表转换成`A2A.Message` (角色为`User`，所有的`AIContent`转换成`A2A.Part`)，并作为`SendMessageRequest`的`Message`属性。如果`A2AAgentSession`携带`TaskId`：
    - 如果任务状态为`InputRequired`（表示任务正在等待输入），则将`TaskId`赋值给`Message`的`TaskId`属性，
    - 否则添加到`ReferenceTaskIds`列表中；
- 将`AgentRunOptions`的`AdditionalProperties`转换成元数据赋值给`SendMessageRequest`的`Metadata`属性；
- 如果`AgentRunOptions`的`AllowBackgroundResponses`为`true`(运行后台响应)，将`Message`的`SendMessageConfiguration`的`ReturnImmediately`设置为`true`。

然后将`SendMessageRequest`作为输入调用`IA2AClient`对象的`SendMessageAsync`方法，并按照如下的方式处理返回的`SendMessageResponse`：

- 如果`PayloadCase`为`SendMessageResponseCase.Message`（返回代表执行结果的消息）:
    - 将响应携带的`ContextId`写入当前的`A2AAgentSession`；
    - 调用如下这个`ConvertToAgentResponse`方法将消息转换成返回的`AgentResponse`。

```csharp
private AgentResponse ConvertToAgentResponse(Message message)
{
    return new AgentResponse
    {
        AgentId = this.Id,
        ResponseId = message.MessageId,
        FinishReason = ChatFinishReason.Stop,
        RawRepresentation = message,
        Messages = [message.ToChatMessage()],
        AdditionalProperties = message.Metadata?.ToAdditionalProperties(),
    };
}
```

- 如果`PayloadCase为SendMessageResponseCase.Task`（返回处理请求的后台任务）：
    - 将响应返回的`ContextId`、T`askId`和`TaskState`写入当前的`A2AAgentSession`；
    - 调用上面定义的`ConvertToAgentResponse`方法将代表后台任务的`AgentTask`转换成返回的`AgentResponse`。

### 4.2 流式调用

在重写的`RunCoreStreamingAsync`方法中，如果指定的`AgentSession`为`null`，会创建一个空的`A2AAgentSession`对象。
- 如果`AgentRunOptions`的`ContinuationToken`不为`null`，则将T`askId`作为参数调用`IA2AClient`对象`SubscribeToTaskAsync`接入指定的后台任务，返回代表响应流的`IAsyncEnumerable<StreamResponse>`对象；
- 否则，按照上述的方式将输入的`ChatMessage`列表转换成`A2A.Message`,并据此创建`SendMessageRequest`对象。最后调用`IA2AClient`对象的`SendStreamingMessageAsync`方法得到代表响应流的`IAsyncEnumerable<StreamResponse>`对象。

接下来异步遍历响应流的每个`StreamResponse`，针对`StreamResponseCase`的不同调用对应的方法创建实时输出的`AgentResponseUpdate`，并将`StreamResponse`携带的`ContextId`、`TaskId`和`TaskState`写入当前的`A2AAgentSession`。

```csharp
//StreamResponseCase.Message
private AgentResponseUpdate ConvertToAgentResponseUpdate(Message message)
{
    return new AgentResponseUpdate
    {
        AgentId = this.Id,
        ResponseId = message.MessageId,
        FinishReason = ChatFinishReason.Stop,
        RawRepresentation = message,
        Role = ChatRole.Assistant,
        MessageId = message.MessageId,
        Contents = message.Parts.ConvertAll(part => part.ToAIContent()),
        AdditionalProperties = message.Metadata?.ToAdditionalProperties(),
    };
}

//StreamResponseCase.Task
private AgentResponseUpdate ConvertToAgentResponseUpdate(AgentTask task)
{
    return new AgentResponseUpdate
    {
        AgentId = this.Id,
        ResponseId = task.Id,
        FinishReason = MapTaskStateToFinishReason(task.Status.State),
        RawRepresentation = task,
        Role = ChatRole.Assistant,
        Contents = task.ToAIContents(),
        ContinuationToken = CreateContinuationToken(task.Id, task.Status.State),
        AdditionalProperties = task.Metadata?.ToAdditionalProperties(),
    };
}

//StreamResponseCase.StatusUpdate
private AgentResponseUpdate ConvertToAgentResponseUpdate(TaskStatusUpdateEvent statusUpdateEvent)
{
    return new AgentResponseUpdate
    {
        AgentId = this.Id,
        ResponseId = statusUpdateEvent.TaskId,
        RawRepresentation = statusUpdateEvent,
        Role = ChatRole.Assistant,
        MessageId = statusUpdateEvent.Status.Message?.MessageId,
        FinishReason = MapTaskStateToFinishReason(statusUpdateEvent.Status.State),
        AdditionalProperties = statusUpdateEvent.Metadata?.ToAdditionalProperties() ?? [],
        Contents = statusUpdateEvent.Status.GetUserInputRequests(),
    };
}

//StreamResponseCase.ArtifactUpdate
private AgentResponseUpdate ConvertToAgentResponseUpdate(TaskArtifactUpdateEvent artifactUpdateEvent)
{
    return new AgentResponseUpdate
    {
        AgentId = this.Id,
        ResponseId = artifactUpdateEvent.TaskId,
        RawRepresentation = artifactUpdateEvent,
        Role = ChatRole.Assistant,
        Contents = artifactUpdateEvent.Artifact.ToAIContents(),
        AdditionalProperties = artifactUpdateEvent.Metadata?.ToAdditionalProperties() ?? [],
    };
}
```
