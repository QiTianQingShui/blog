# [A2A协议与实现-07]如何将一个MAF Agent发布为A2A服务[HTTP-JSON]

A2A协议本身并未绑定具体的传入协议，[上一篇](https://blog.csdn.net/JaydenAI/article/details/163197422)主要介绍如何将MAF的Agent以`JSON-RPC`协议发布为A2A服务，这篇文章我们采用相同的形式介绍基于单纯HTTP+JSON的实现。两者的区别很简单，前者将请求和响应消息包装进成符合J`SON-RPC`协议的**封套**，并使用JSON-RPC Method来标识具体的操作，后者直接以请求和响应消息的JSON文本作为传输的内容，通过为每个操作绑定一个固定的路径来区分。

## 1. 构建A2A服务器

[上一篇](https://blog.csdn.net/JaydenAI/article/details/163197422)定义了辅助方法`StartA2aServerAsync`来完成整个A2A服务器的构建和启动，这里我们只需要修改一行代码：将针对A2A路由终结点的注册的方法从之前的`MapA2AJsonRpc`改成如下所示的`MapA2AHttpJson`即可，这里我们直接使用根路径，并且省去了针对`AgentCard`对应终结点的注册。

```csharp
static async Task StartA2aServerAsync(Uri url, Action<A2AServerRegistrationOptions>? configureOptions = null)
{
    Env.Load();
    var apiKey = Environment.GetEnvironmentVariable("OPENAI_API_KEY")!;
    var endpoint = Environment.GetEnvironmentVariable("OPENAI_BASE_URL")!;

    var agent = new OpenAIClient(
        credential: new ApiKeyCredential(key: apiKey),
        options: new OpenAIClientOptions { Endpoint = new Uri(endpoint) })
    .GetResponsesClient()
    .AsAIAgent(model: "gpt-5.4-mini", name: "a2a-agent");

    var buidler = WebApplication.CreateBuilder();
    buidler.Services
        .AddA2AServer(agent.Name!, configureOptions)
        .AddAIAgent(agent.Name!, (services, anme) => agent)
       ;
    buidler.WebHost.UseUrls(url.ToString());
    var app = buidler.Build();
    app.MapA2AHttpJson(agent,"/");
    await app.StartAsync();
}
```

## 2. Agent的阻塞式调用

如下的程序演示了针对A2A Agent阻塞式调用。如代码所示，我们指定了A2A服务器的监听地址（http://localhost:3721/）调用`StartA2aServerAsync`启动了A2A服务器。然后我们创建了作为输入消息的`SendMessageRequest`对象，我们知道它相当于一个角色为**User**的`ChatMessage`。我们将它作为输入调用InvokeAsync方法以阻塞方式调用以A2A服务器承载的`AIAgent`，并得到作为响应消息的`SendMessageResponse`。响应消息将主体内容置于`Parts`属性表示的`Part`对象中，我们将它们的文本输出到控制台上。

```csharp
var url = new Uri("http://localhost:3721/");
await StartA2aServerAsync(url);
using var httpClient = new HttpClient { BaseAddress = url };
var request = new SendMessageRequest
{
    Message = new Message
    {
        Role = Role.User,
        Parts = [Part.FromText("给出战国四公子的名字")]
    }
};
var response = await InvokeAsync<SendMessageResponse>("/message:send", request, httpClient);
foreach (var part in response!.Message!.Parts)
{
    Console.Write(part.Text);
}
```

输出：

```markdown

1. **齐国孟尝君**——田文
2. **赵国平原君**——赵胜
3. **魏国信陵君**——魏无忌
4. **楚国春申君**——黄歇

如果你愿意，我也可以顺便给你讲一下他们各自的典故。
```

如下所示的是`InvokeAsync<TResponse>`方法的定义，它的三个参数分别代表：A2A操作绑定的路径（Agent的阻塞式调用操作对应的路径为`/message:send`）、请求消息和用来进行远程调用的`HttpClient`对象。由于不需要将请求消息包装成标准的JSON-RPC数据结构，而是直接传输请求消息的JSON文本，所以这个方法的定义非常简单。我们直接指定请求的路径、请求消息和基于A2A默认采用的`JsonSerializerOptions`调用`HttpClien`t的`PostAsJsonAsync`方法，并将响应消息的主体内容反序列化成泛型参数`TResponse`就可以了。

```csharp
async Task<TResponse?> InvokeAsync<TResponse>( string path, object request, HttpClient httpClient)
{
    using var response = await httpClient.PostAsJsonAsync(path, request, A2AJsonUtilities.DefaultOptions);
    response.EnsureSuccessStatusCode();
    using var stream = await response.Content.ReadAsStreamAsync();
    return await JsonSerializer.DeserializeAsync<TResponse>(stream, A2AJsonUtilities.DefaultOptions);
}
```

## 3. Agent的流式调用

如下的程序演示了以流的形式远程调用承载与A2A服务器的Agent。具体的调用的方法为`StreamAsync<TResult>`，该方法具有与`InvokeAsync`方法一致的参数定义。从第一个指定的参数可以看出，A2A服务器接收Agent流式调用请求的路径为`/message:stream`。所谓的**流**体现在返回的`IAsyncEnumerable<StreamResponse>`对象上。我们一般迭代每个`StreamResponse`，并将其封装的消息文本输出到控制台上。

```csharp
var url = new Uri("http://localhost:3721/");
await StartA2aServerAsync(url);
using var httpClient = new HttpClient { BaseAddress = url };
var request = new SendMessageRequest
{
    Message = new Message
    {
        Role = Role.User,
        Parts = [Part.FromText("给出战国四公子的名字")]
    }
};
await foreach (var update in StreamAsync<StreamResponse>("/message:stream", request, httpClient))
{
    foreach (var part in update.Message!.Parts)
    {
        Console.Write(part.Text);
    }
}
```

输出：

```markdown
战国四公子通常指：

1. **魏国信陵君** —— **魏无忌**
2. **赵国平原君** —— **赵胜**
3. **齐国孟尝君** —— **田文**
4. **楚国春申君** —— **黄歇**

如果你愿意，我也可以继续给你补充这四位的主要事迹和各自的特点。
```

和基于`JSON-RPC`的流式实现一样，`HTTP-JSON`底层的传输协议依然是`SSE`，所以`StreamAsync<TResult>`方法的核心操作依然是发送请求，并使用`SseParser`以及解析每个抵达的SSE数据项，最终将内容反序列化成`TResult`对象。由于直接采用的是承载请求和响应消息的**裸JSON**，所以`StreamAsync<TResult>`省去了基于`JSON-RPC`针对请求的封装和针对响应的解封。

```csharp
async IAsyncEnumerable<TResult> StreamAsync<TResult>(string path, object request, HttpClient httpClient)
{
    using var response = await httpClient.PostAsJsonAsync(path, request, A2AJsonUtilities.DefaultOptions);
    response.EnsureSuccessStatusCode();
    using var stream = await response.Content.ReadAsStreamAsync();
    using (response)
    using (stream)
    {
        await foreach (var sseItem in SseParser.Create(stream).EnumerateAsync())
        {
            yield return JsonSerializer.Deserialize<TResult>(sseItem.Data, A2AJsonUtilities.DefaultOptions)!;
        }
    }
}
```
