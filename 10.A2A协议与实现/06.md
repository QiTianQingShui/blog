# [A2A协议与实现-06]如何将一个MAF Agent发布为A2A服务[JSON-RPC]

这个系列之前的文章对A2A协议本身提供了系统介绍，而且还提供了针对LangChain的A2A服务构建方式。借助于A2A SDK，MAF针对A2A提供了很好的支持，这篇文章通过几个简单的例子演示如何在一个ASP.NET Core应用构建A2A Server。A2A自身并未绑定到具体的传输协议，MAF分别提供针对JSON-RPC和HTTP-JSON两种协议的支持，本篇文章主要关注前者，[下一篇](https://blog.csdn.net/JaydenAI/article/details/163212145?spm=1001.2014.3001.5502)会介绍后者。

## 1. 构建A2A服务器

我们常见一个简单ASP.NET Core应用，并添加针对如下NuGet包的引用。我们依然使用基于OpenAI的GPT模型，所以将相关的设置写入`.env`文件中，并利用`DotNetEnv`写入环境变量。

- DotNetEnv
- Microsoft.Agents.AI
- Microsoft.Agents.AI.A2A
- Microsoft.Agents.AI.Hosting.A2A.AspNetCore
- Microsoft.Agents.AI.OpenAI

我们定义了如下这个`StartA2aServerAsync`静态来完成所有的工作，它的参数分别表示指定的服务器监听地址和针对A2A Server的设置。如代码所示，我们创建了一个`AIAgent`对象和一个描述它的`AgentCard`。我们调用`WebApplication`的`MapWellKnownAgentCard`扩展方法注册了一个GET终结点发布`AgentCard`，调用`MapA2AJsonRpc`扩展方法注册了POST终结点以`JSON-PRC`协议调用指定的`AIAgent`。在这之前，我们调用了`IServiceCollection`的`AddA2AServer`和`AddAIAgent`扩展方法注册了依赖的服务。

```csharp
static async Task StartA2aServerAsync(Uri url, Action<A2AServerRegistrationOptions>? configureOptions = null)
{
    Env.Load();
    var apiKey = Environment.GetEnvironmentVariable("OPENAI_API_KEY")!;
    var endpoint = Environment.GetEnvironmentVariable("OPENAI_BASE_URL")!;
    var agent = new OpenAIClient(new ApiKeyCredential(apiKey), new OpenAIClientOptions { Endpoint = new Uri(endpoint) })
    .GetChatClient(model: "gpt-5.4-mini")
    .AsIChatClient()
    .AsAIAgent(name: "a2a-agent");

    var agentCard = new AgentCard
    {
        Name = "a2a-agent",
        Description = "Agent for A2A testing.",
        Version = "1.0.0",
        DefaultInputModes = ["text", "text/plain"],
        DefaultOutputModes = ["text", "text/plain"],
        SupportedInterfaces = [
            new AgentInterface{
            ProtocolBinding = "JSONRPC",
            ProtocolVersion = "2.0",
            Url = $"{url}/json-rpc"
        }],
        Capabilities = new AgentCapabilities { Streaming = true, PushNotifications = true },
        Skills = [
           new A2A.AgentSkill
       {
            Id="skill-1",
            Name="1st skill",
            Description="this is 1st skill for testing",
            Tags=["t1", "t2", "T3"]
       }
        ],
    };

    var buidler = WebApplication.CreateBuilder();
    buidler.Services
        .AddA2AServer(agent.Name, configureOptions)
        .AddAIAgent(agent.Name, (services, anme) => agent);
    buidler.WebHost.UseUrls(url.ToString());
    var app = buidler.Build();    
    app.MapWellKnownAgentCard(agentCard);
    app.MapA2AJsonRpc(agent, "/json-rpc");
    await app.StartAsync();
}
```

## 2. 读取AgentCard信息

`MapWellKnownAgentCard`方法调用会以标准的路径`.well-known/agent-card.json`来发布`AgentCard`的内容。所以我们可以直接请求此路径便可得到承载Agent基本信息的`AgentCard`。在如下的演示程序中，我们调用上面定义的这个`StartA2aServerAsync`方法以指定的URL构建并启动A2A Server。然后直接利用创建的`HttpClient`对目标地址发送一个GET请求，并将读取的内容反序列化成`AgentCard`对象。 我们最后调用`WriteJsonAsync`方法以格式化JSON的形式将其输出。

```csharp
var url = new Uri("http://localhost:3721/");
await StartA2aServerAsync(url);

using var httpClient = new HttpClient {  BaseAddress = url};
var agentCard = await httpClient.GetFromJsonAsync<AgentCard>(".well-known/agent-card.json");
WriteJson(agentCard);

static void WriteJson(object message)
{
    Console.WriteLine(JsonSerializer.Serialize(message, new JsonSerializerOptions {
        Encoder = JavaScriptEncoder.UnsafeRelaxedJsonEscaping,
        WriteIndented = true,        
    }));
}
```

## 3. 阻塞式调用Agent

A2A针对Agent的调用提供了**阻塞式**和**流式**两种。在如下针对阻塞式调用的演示程序中，我们创建了一个`SendMessageRequest`对象作为请求，相当于是构建了一个角色为**User**的`ChatMessage`。并将其作为输入调用我们定义的`InvokeAsync`方法来以A2A的方式远程调用Agent。由于采用`JSON-RPC`协议，所以每个请求都需要携带对应的`Method`。根据前面针对A2A协议的介绍，我们知道阻塞式Agent调用采用的JSON-RPC Method是就是`SendMessage`。

```csharp
var url = new Uri("http://localhost:3721/");
await StartA2aServerAsync(url);
using var httpClient = new HttpClient { BaseAddress = url };
var request = new SendMessageRequest
{
    Message = new Message
    {
        Role = Role.User,
        Parts = [Part.FromText("给出战国四公子的名字")]
    }
};
var response = await InvokeAsync<SendMessageResponse>("SendMessage", request);
foreach (var part in response.Message.Parts)
{
    Console.Write(part.Text);
}
```
输出：

```markdown
战国四公子通常指：

1. **齐国孟尝君**——田文
2. **赵国平原君**——赵胜
3. **魏国信陵君**——魏无忌
4. **楚国春申君**——黄歇
```

调用`InvokeAsync`方法以`SendMessageResponse`对象的形式返回Agent的响应。`SendMessageResponse`的`Message`属性返回一个类似于`ChatMessage`的`Message`对象，正如`ChatMessage`利用`Contents`属性返回承载的内容一样，这里的消息将内容置于`Parts`属性中。我们将每个`Part`的文本内容依次输出来。

`InvokeAsync`方法定义如下，泛型类型`TResponse`表示作为调用结果的类型。如代码所示，我们将指定的参数作为`Method`和`Params`创建了作为`JSON-RPC`请求的`JsonRpcRequest`对象，并将其作为输入调用`HttpClient`的`PostAsJsonAsync`方法，并得到作为响应的`JsonRpcResponse`对象。我们最后将`JsonRpcResponse`的`Result`反序列化成`TResponse`对象并返回。

```csharp
async Task<TResponse> InvokeAsync<TResponse>( string method, object request)
{    
    var rpcRequest = new JsonRpcRequest
    {
        Method = method,
        Id = new JsonRpcId(Guid.NewGuid().ToString()),
        Params = new JsonElement?(JsonSerializer.SerializeToElement(request, A2AJsonUtilities.DefaultOptions))
    };
    var response = await httpClient.PostAsJsonAsync("json-rpc", rpcRequest);
    response.EnsureSuccessStatusCode();
    var rpcResponse = await response.Content.ReadFromJsonAsync<JsonRpcResponse>();
    return rpcResponse.Result.Deserialize<TResponse>(A2AJsonUtilities.DefaultOptions);
}
```

## 4. 流式调用Agent

由于流式调用Agent可以实时输出生成的内容，在应用上的体现主要表示为逐字输出实时返回的内容，能够带来更好的用户体验。在如下所示的演示程序中，我们创建相同的方式创建了`SendMessageRequest`对象，并将它作为输入调用`StreamAsync<StreamResponse>`方法以流的形式远程调用Agent。由于流式调用对应的`JSON-RPC`方法名称为`SendStreamingMessage`，我们将它作为调用`StreamAsync<StreamResponse>`方法的第一个参数。该方法返回一个`IAsyncEnumerable<StreamResponse>`对象，我们异步迭代每个`StreamResponse`，并将它的消息携带的所有文本内容输出来。

```csharp
var url = new Uri("http://localhost:3721/");
await StartA2aServerAsync(url);
using var httpClient = new HttpClient { BaseAddress = url };
var request = new SendMessageRequest
{
    Message = new Message
    {
        Role = Role.User,
        Parts = [Part.FromText("给出战国四公子的名字")]
    }
};
await foreach (var response in StreamAsync<StreamResponse>("SendStreamingMessage", request))
{
    foreach (var part in response .Message.Parts)
    {
        Console.Write(part.Text);
    }
}
```

输出：

```markdown
战国四公子是：

1. **孟尝君** —— 田文，齐国
2. **平原君** —— 赵胜，赵国
3. **信陵君** —— 魏无忌，魏国
4. **春申君** —— 黄歇，楚国
```

如下所示的是`StreamAsync`方法的定义。我们采用与`InvokeAsync`类似的方式将原始的输入对象封装成`JsonRpcRequest`。由于我们构建的A2A Server会采用`SSE`协议实现流式输出，所以整个过程就是一个**采用`SseParser`解析每个`SSE`数据项，并反序列化生成并输出结果的过程**。

```csharp
async IAsyncEnumerable<TResult> StreamAsync<TResult>( string method, object request,)
{
    var rpcRequest = new JsonRpcRequest
    {
        Method = method,
        Id = new JsonRpcId(Guid.NewGuid().ToString()),
        Params = new JsonElement?(JsonSerializer.SerializeToElement(request, A2AJsonUtilities.DefaultOptions))
    };

    using var content = new JsonRpcContent(rpcRequest);
    using var requestMessage = new HttpRequestMessage(HttpMethod.Post, "json-rpc")
    {
        Content = content,
    };
    requestMessage.Headers.TryAddWithoutValidation("A2A-Version", "1.0");
    requestMessage.Headers.Accept.Add(new System.Net.Http.Headers.MediaTypeWithQualityHeaderValue("text/event-stream"));

    var response = await httpClient.SendAsync(requestMessage, HttpCompletionOption.ResponseHeadersRead).ConfigureAwait(false);
    response.EnsureSuccessStatusCode();

    var stream = await response.Content.ReadAsStreamAsync().ConfigureAwait(false);
    using (response)
    using (stream)
    {
        await foreach (var sseItem in SseParser.Create(stream).EnumerateAsync())
        {
            var rpcResponse = JsonSerializer.Deserialize<JsonRpcResponse>(sseItem.Data, A2AJsonUtilities.DefaultOptions);
            var result = rpcResponse.Result.Deserialize<TResult>(A2AJsonUtilities.DefaultOptions);
            yield return result;
        }
    }
}
```
