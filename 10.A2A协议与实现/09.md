# [A2A协议与实现-09].NET SDK客户端的设计与实现

A2A的协议提供了四组核心操作的输入和输出数据结构（可以参考我的前面的文章[从Protobuf消息详解A2A协议四大核心操作](https://blog.csdn.net/JaydenAI/article/details/161178382)），如何进一步知道具体采用的传输协议，我就可以直接利用HttpClient来编写A2A客户端代码，实际上前面的演示都是这么做得。实际上A2A官方针对.NET的SDK提供了客户端实现。

## 1. IA2AClient

[A2A协议与实现-03：从Protobuf消息详解A2A协议四大核心操作](https://blog.csdn.net/JaydenAI/article/details/161178382)从协议的角度解读了A2A的四组核心操作，[A2A协议与实现-08：基于MAF的A2A Server设计与实现](https://blog.csdn.net/JaydenAI/article/details/163221166)介绍了`IA2ARequestHandler`接口，我们说它是A2A服务端SDK对A2A协议的表达，如下这个`IA2AClient`具有与`IA2ARequestHandler`接口完全一致的定义，则是客户端SDK针对A2A协议的表达。我们自然可以利用它的实现来执行A2A的四组核心操作。

```csharp
public interface IA2AClient
{
    // 1. Agent调用
	Task<SendMessageResponse> SendMessageAsync(
        SendMessageRequest request, 
        CancellationToken cancellationToken = default);
	IAsyncEnumerable<StreamResponse> SendStreamingMessageAsync(
        SendMessageRequest request, 
        CancellationToken cancellationToken = default);
    
    // 2. 后台任务管理
	Task<AgentTask> GetTaskAsync(
        GetTaskRequest request, 
        CancellationToken cancellationToken = default);
	Task<ListTasksResponse> ListTasksAsync(
        ListTasksRequest request, 
        CancellationToken cancellationToken = default);
	Task<AgentTask> CancelTaskAsync(
        CancelTaskRequest request, 
        CancellationToken cancellationToken = default);
	IAsyncEnumerable<StreamResponse> SubscribeToTaskAsync(
        SubscribeToTaskRequest request, 
        CancellationToken cancellationToken = default);
    
    // 3. 基于后台任务的通知推送配置管理
	Task<TaskPushNotificationConfig> CreateTaskPushNotificationConfigAsync(
        CreateTaskPushNotificationConfigRequest request, 
        CancellationToken cancellationToken = default);
	Task<TaskPushNotificationConfig> GetTaskPushNotificationConfigAsync(
        GetTaskPushNotificationConfigRequest request, 
        CancellationToken cancellationToken = default);
	Task<ListTaskPushNotificationConfigResponse> ListTaskPushNotificationConfigAsync(
        ListTaskPushNotificationConfigRequest request, 
        CancellationToken cancellationToken = default);        
	Task DeleteTaskPushNotificationConfigAsync(
        DeleteTaskPushNotificationConfigRequest request, 
        CancellationToken cancellationToken = default);

    // 4. AgetCard扩展    
	Task<AgentCard> GetExtendedAgentCardAsync(GetExtendedAgentCardRequest request, CancellationToken cancellationToken = default);
}
```

## 2. 针对JSON-RPC的实现

既然是对A2A协议的表达，`IA2AClient`接口自然与具体的传输协议无关，但是具体的实现则不得不考虑底层采用的传输协议。如下所示的`A2AClient`类型是针对`JSON-RPC`的实现。我们在初始化`A2AClient`对象的时候只需要提供A2A Server的基础地址和一个可选的`HttpClient`对象。具体的实现很简单，不外乎就是使用操作对应的Method为请求封装成`JSON-RPC`封套以POST形式发送。如果采用流式调用，由于服务端会采用SSE实时回传生成的内容，这里只需要采用对应的方式解析SSE数据项即可。

```csharp
public sealed class A2AClient : IA2AClient, IDisposable
{
	public A2AClient(Uri baseUrl, HttpClient? httpClient = null);
    ...
}
```

如下所示的是采用A2AClient以阻塞方式调用Agent的例子。

```csharp
using A2A;
using Azure.AI.Projects;
using DotNetEnv;
using Microsoft.Agents.AI.Hosting;
using Microsoft.Extensions.AI;
using OpenAI;
using OpenAI.Responses;
using System.ClientModel;

Env.Load();
var apiKey = Environment.GetEnvironmentVariable("OPENAI_API_KEY")!;
var endpoint = Environment.GetEnvironmentVariable("OPENAI_BASE_URL")!;

var agent = new OpenAIClient(
    credential: new ApiKeyCredential(key: apiKey),
    options: new OpenAIClientOptions { Endpoint = new Uri(endpoint) })
.GetResponsesClient()
.AsAIAgent(
    model: "gpt-5.4-mini", 
    name: "a2a-agent",
    instructions: """
    你是一个深谙中国古代历史的专家，善于根据正史，以公正客观的态度于人交流历史问题。
    对于用户提出的问题，请以简介概括性的语言予以答复，字数尽量保持在200字以内。
    """);

var buidler = WebApplication.CreateBuilder();
buidler.Services
    .AddA2AServer(agent.Name!)
    .AddAIAgent(agent.Name!, (services, anme) => agent)
   ;
var url = "http://localhost:3721/";
buidler.WebHost.UseUrls(url);
var app = buidler.Build();
app.MapA2AJsonRpc(agent, "/");
await app.StartAsync();

using var client = new A2AClient(new Uri(url));
var prompt = "春秋初霸郑庄公寤生为何没有成为春秋五霸，是因为郑国不够强大吗？";
var request = new SendMessageRequest
{
    Message = new Message { Role = Role.User, Parts = [new Part { Text = prompt }] },
};

var response = await client.SendMessageAsync(request);
foreach (var part in response.Message!.Parts)
{ 
    Console.WriteLine(part.Text);
}
```

输出：

```
不完全是。郑庄公在春秋初年确实一度称霸，尤其在“周郑交质”“射王中肩”等事件后，威望很高，但郑国的霸业有明显局限：一是国土狭小、人口与资源有限，难以长期支撑霸权；二是地处四战之地，易受周边大国夹击；三是郑庄公之后继承者能力不足，国力很快衰落。
“春秋五霸”本身也是后世概括，通常重在齐桓公、晋文公等更具持续影响者，所以郑庄公常被视为“春秋初霸”，而不列入五霸。
```

如果希望通过逐字输出的效果，可以按照如下的方式采用流式调用：

```csharp
await foreach (var response in client.SendStreamingMessageAsync(request))
{
    foreach (var part in response.Message!.Parts)
    {
        Console.Write(part.Text);
    }
}
```

## 3. 针对HTTP-JSON的实现

如果A2A Server是采用HTTP-JSON协议构建，那么就需要使用如下这个对应的客户端类型`A2AHttpJsonClient`。它与`OpenAIClient`具有完全一致的构造函数定义。

```csharp
public sealed class A2AHttpJsonClient : IA2AClient, IDisposable
{
    public A2AHttpJsonClient(Uri baseUrl, HttpClient? httpClient = null);
    ...
}
```

我们将上面演示的程序切换成HTTP-JSON协议，并采用`A2AHttpJsonClient`作为调用客户端。

```csharp
using A2A;
using Azure.AI.Projects;
using DotNetEnv;
using Microsoft.Agents.AI.Hosting;
using Microsoft.Extensions.AI;
using OpenAI;
using OpenAI.Responses;
using System.ClientModel;

Env.Load();
var apiKey = Environment.GetEnvironmentVariable("OPENAI_API_KEY")!;
var endpoint = Environment.GetEnvironmentVariable("OPENAI_BASE_URL")!;

var agent = new OpenAIClient(
    credential: new ApiKeyCredential(key: apiKey),
    options: new OpenAIClientOptions { Endpoint = new Uri(endpoint) })
.GetResponsesClient()
.AsAIAgent(
    model: "gpt-5.4-mini", 
    name: "a2a-agent",
    instructions: """
    你是一个深谙中国古代历史的专家，善于根据正史，以公正客观的态度于人交流历史问题。
    对于用户提出的问题，请以简介概括性的语言予以答复，字数尽量保持在200字以内。
    """);

var buidler = WebApplication.CreateBuilder();
buidler.Services
    .AddA2AServer(agent.Name!)
    .AddAIAgent(agent.Name!, (services, anme) => agent)
   ;
var url = "http://localhost:3721/";
buidler.WebHost.UseUrls(url);
var app = buidler.Build();
app.MapA2AHttpJson(agent, "/");
await app.StartAsync();

using var client = new A2AHttpJsonClient(new Uri(url));
var prompt = "春秋初霸郑庄公寤生为何没有成为春秋五霸，是因为郑国不够强大吗？";
var request = new SendMessageRequest
{
    Message = new Message { Role = Role.User, Parts = [new Part { Text = prompt }] },
};

Console.WriteLine($"{new string('-', 20)}SendMessageAsync{new string('-', 20)}");
var response = await client.SendMessageAsync(request);
foreach (var part in response.Message!.Parts)
{
    Console.WriteLine(part.Text);
}

Console.WriteLine($"{new string('-', 20)}SendStreamingMessageAsync{new string('-', 20)}");
await foreach (var update in client.SendStreamingMessageAsync(request))
{
    foreach (var part in update.Message!.Parts)
    {
        Console.Write(part.Text);
    }
}
Console.ReadLine();
```

输出：

```markdown
--------------------SendMessageAsync--------------------
不是主要因为“郑国不够强大”，而是郑庄公的霸业更偏“春秋初期的权力中心”，难以长期维持。

郑庄公确实曾挟强郑、制诸侯、周旋王室，一度有霸主气象，但郑国地处中原四战之地，国小地狭，战略纵深不足；加之庄公死后国力迅速下滑，未能形成持续稳定的霸权体系。
而后来的“五霸”多是长期扩张、能整合资源并持续主盟的强国君主，所以郑庄公虽有“初霸”之名，终究未列入传统春秋五霸。

--------------------SendStreamingMessageAsync--------------------
不只是“郑国不够强大”，更关键是郑庄公的霸业具有明显的**短暂性和局部性**。春秋初年“霸”多指能号令诸侯、主持会盟者，郑庄公虽曾挟王室、败强邻，威震一时，但其影响主要限于中原局部，且未形成长期稳定的盟主地位。此后郑国国力有限，又屡受宋、楚、齐等国压力，难以延续霸权。后来“五霸”之所以被后世定型，更多是因为其霸业更持久、影响更大、史书叙事也更集中。
```
