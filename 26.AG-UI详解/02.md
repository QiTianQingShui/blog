# [AG-UI详解-02]AG-UI Agent服务的承载和调用

AG-UI本质上是一个建立在HTTP/SEE上的消息交换协议，整个协议分服务端和客户端两部分。Web服务端暴露一个终结点（Endpoint）并于一个AIAgent绑定，它接受客户端的请求并采用流的形式调用AIAgent，实时返回的AgentResponseUpdate承载的内容写入SSE连接实时反馈给客户端。

## 1. 从输入开始说起

在[AG-UI详解-01：创建一个类ChatGPT应用与Agent实时交互]()提供的演示程序中，我们拦截了客户端的调用请求，发现它是一个具有如下结构的JSON。

```json
{
  "threadId": "thread_eb2bd3b287494deb8736f079863bdbc7",
  "runId": "run_8f8ed2f303824ab6acc9875e9ebdf908",
  "messages": [
    {
      "name": null,
      "id": "1d008f8827e044758e1de9e44bd13989",
      "role": "user",
      "content": "战国四大名将一般指的是谁？"
    }
  ],
  "context": []
}
```

这个JSON反映了AG-UI客户端输入的部分结构。具体来说，AG-UI客户端SDK利用如下这个名为RunAgentInput的数据类型来表示客户端以AG-UI协议运行Agent的输入。

```csharp
internal sealed class RunAgentInput
{    
    public string ThreadId { get; set; } = string.Empty;
    public string RunId { get; set; } = string.Empty;
    public JsonElement State { get; set; }
    public IEnumerable<AGUIMessage> Messages { get; set; } = Array.Empty<AGUIMessage>();
    public IEnumerable<AGUITool>? Tools { get; set; }
    public AGUIContextItem[] Context { get; set; } = Array.Empty<AGUIContextItem>();
    public JsonElement ForwardedProperties { get; set; }
}
```
