# [FastMCP设计、原理与应用-19]客户端采样:让客户端成为MCP服务端的“大脑”

LLM采样功能允许您的MCP工具在执行期间向客户端LLM请求文本生成。这使得工具能够利用AI功能进行分析、生成、推理等操作，而无需客户端协调多次调用。

## 1. 客户端向服务端提供LLM服务

在下面的演示程序中，我们为创建的FastMCP注册了两个工具：`get_wheather`用于获取指定城市的天气信息，`get_clothing_suggestions`工具提供指定城市当前的着装建议。在`get_clothing_suggestions`工具执行过程中，我们调用`Context`的`sample`方法回调客户端LLM。我们指定了消息和系统提示词，并提供了用于提供天气新的的工具`get_wheather`。

```python
from fastmcp import FastMCP, Context
from fastmcp.client import Client
from mcp.types import  SamplingCapability,SamplingToolsCapability
from fastmcp.client.sampling.handlers.openai import OpenAISamplingHandler
from dotenv import load_dotenv
import asyncio

load_dotenv()

mcp = FastMCP()
@mcp.tool
async def get_wheather(city: str) -> str:
    """获取指定城市的天气信息。"""
    return f"当前{city}的天气是晴朗，温度25摄氏度。"

@mcp.tool
async def get_clothing_suggestions(city: str, ctx: Context) -> str:
    """根据指定城市的天气信息，提供穿衣建议。"""
    result = await ctx.sample(
        messages= f"请根据{city}的天气信息提供穿衣建议。",
        system_prompt="你是一个时尚专家和养生顾问，请根据天气信息提供穿衣建议",
        tools=[get_wheather],)
    return result.text or ""    

async def main():
    async with Client(
        mcp, 
        sampling_handler = OpenAISamplingHandler(default_model="gpt-5.2-chat"), #type: ignore
        sampling_capabilities = SamplingCapability(tools=SamplingToolsCapability())) as client:
        result = await client.call_tool(name="get_clothing_suggestions", arguments={"city": "苏州"})
        print(result.content[0].text) # type: ignore

asyncio.run(main())  
```

在构建`Client`的时候，我们创建了一个`OpenAISamplingHandler`对象作为`sampling_handler`，并将模型名称设置为`gpt-5.2-chat`。其他相关的设置（API KEY和BASE_URL）写入.env文件中，通过调用dotenv.`load_dotenv`函数写入环境变量。由于LLM采样涉及工具调用，需要利用另一个`sampling_capabilities`参数声明支持此项功能。然后我们调用指定城市（苏州）调用`get_clothing_suggestions`工具，会得到如下所示的穿衣建议。从第一句可以看出，LLM采用会自动调用`get_wheather`工具，并根据返回的天气做出着装建议。

## 2. 服务端发起LLM采样请求

LLM采样通过调用`Context`如下所示的`sample_step`和`sample`方法，前者只会进行单步推理，只会涉及一次LLM调用；后者可以执行一轮完整的循环直至得到最终的答案。

```python
@dataclass
class Context:
    async def sample_step(
        self,
        messages: str | Sequence[str | SamplingMessage],
        *,
        system_prompt: str | None = None,
        temperature: float | None = None,
        max_tokens: int | None = None,
        model_preferences: ModelPreferences | str | list[str] | None = None,
        tools: Sequence[SamplingTool | Callable[..., Any]] | None = None,
        tool_choice: ToolChoiceOption | str | None = None,
        execute_tools: bool = True,
        mask_error_details: bool | None = None,
        tool_concurrency: int | None = None,
    ) -> SampleStep

    @overload
    async def sample(
        self,
        messages: str | Sequence[str | SamplingMessage],
        *,
        system_prompt: str | None = None,
        temperature: float | None = None,
        max_tokens: int | None = None,
        model_preferences: ModelPreferences | str | list[str] | None = None,
        tools: Sequence[SamplingTool | Callable[..., Any]] | None = None,
        result_type: type[ResultT],
        mask_error_details: bool | None = None,
        tool_concurrency: int | None = None,
    ) -> SamplingResult[ResultT]

    @overload
    async def sample(
        self,
        messages: str | Sequence[str | SamplingMessage],
        *,
        system_prompt: str | None = None,
        temperature: float | None = None,
        max_tokens: int | None = None,
        model_preferences: ModelPreferences | str | list[str] | None = None,
        tools: Sequence[SamplingTool | Callable[..., Any]] | None = None,
        result_type: None = None,
        mask_error_details: bool | None = None,
        tool_concurrency: int | None = None,
    ) -> SamplingResult[str]

    async def sample(
        self,
        messages: str | Sequence[str | SamplingMessage],
        *,
        system_prompt: str | None = None,
        temperature: float | None = None,
        max_tokens: int | None = None,
        model_preferences: ModelPreferences | str | list[str] | None = None,
        tools: Sequence[SamplingTool | Callable[..., Any]] | None = None,
        result_type: type[ResultT] | None = None,
        mask_error_details: bool | None = None,
        tool_concurrency: int | None = None,
    ) -> SamplingResult[ResultT] | SamplingResult[str]    
```

上述方法设置的参数说明如下：

- **messages**：对话历史。可以是简单的字符串，也可以是`SamplingMessage`列表；
- **system_prompt**：系统提示词；
- **temperature**：决定文本生成随机性和创意性的“维度”。0为严谨，1 为发散；
- **max_tokens**：限制LLM这一步输出的长度（以Token计量）。
- **model_preferences**：模型偏好。可以指定希望用哪种等级的模型（如 "fast", "powerful"）或者具体的模型名称列表，由客户端决定最终调度哪个;
- **tools**：告诉LLM这一步它能用哪些工具;
- **tool_choice**: 强制工具策略：
    - "none": 不准调工具；
    - "auto": 自动决定；
    - "any" / "required": 必须调一个工具；
    - 或者指定某个具体的工具名；
- **execute_tools**：对于单步推理，如果返回消息携带表示工具调用意图的ToolCall，决定是直接返回当前消息，还是调用这些工具返回工具执行的结果；
- **result_type**：结构化输出Schema类型；
- **tool_concurrency**: 如果涉及多个工具调用，这里用于设置工具调用的并发度；
- **mask_error_details**: 如果工具执行报错，是否向LLM隐藏具体的Python堆栈信息，防止泄露后端隐私。

## 3. 客户端处理采样请求

客户端在创建`Client`的时候，通过将构造函数的`sampling_handler`参数指定为一个`SamplingHandler`来处理LLM采样请求。`SamplingHandler`这个可执行对象的签名如下：

```python
SamplingHandler: TypeAlias = Callable[
    [
        list[SamplingMessage],
        SamplingParams,
        RequestContext[SessionT, LifespanContextT],
    ],
    SamplingHandlerResult | Awaitable[SamplingHandlerResult],
]
```

`SamplingHandler`这个可执行对象具有三个参数。第一个参数为代表一段对话历史的`SamplingMessage`列表，我们将它作为调用LLM的输入。`SamplingMessage`类型定义如下，它利用`role`字段绑定角色，并利用`content`提供内容（可以是文本，也可以是其他多媒体内容）

```python
class SamplingMessage(BaseModel):
    role: Role
    content: SamplingMessageContentBlock | list[SamplingMessageContentBlock]
    meta: dict[str, Any] | None
    model_config = ConfigDict(extra="allow")

    @property
    def content_as_list(self) -> list[SamplingMessageContentBlock]

SamplingMessageContentBlock: TypeAlias = TextContent | ImageContent | AudioContent | ToolUseContent | ToolResultContent
Role = Literal["user", "assistant"]
```

`SamplingHandler`的第二个参数的类型为`CreateMessageRequestParams`（`SamplingParams`），它由服务端调用`sample`/`sample_step`方法时传入的除`messages`以外的其他参数构建而成，所以你会看到其字段定义与`sample`/`sample_step`方法参数定义很类似。第三个参数代表当前请求上下文的`RequestContext`对象。

```python
from mcp.types import CreateMessageRequestParams as SamplingParams
class CreateMessageRequestParams(RequestParams):
    messages: list[SamplingMessage]
    modelPreferences: ModelPreferences | None = None
    systemPrompt: str | None = None
    includeContext: IncludeContext | None = None
    temperature: float | None = None
    maxTokens: int
    tools: list["Tool"] | None = None
    toolChoice: ToolChoice | None = None
    model_config = ConfigDict(extra="allow")
```

调用LLM返回的结果被封装成一个`SamplingHandlerResult`对象，并作为`SamplingHandler`的返回值。可以是单纯的字符串文本（针对传统的Completion模型）也可以是一个绑定为某个角色（通常为“assistant”）的消息（针对Chat模型），通过`CreateMessageResulth`或者`CreateMessageResultWithTools`对象表示，前者的内容不含工具调用，所以类型为`SamplingContent`（TextContent | ImageContent | AudioContent），后者的内容携带一个或者多一个工具调用，所以类型为`SamplingMessageContentBlock`或者`SamplingMessageContentBlock`列表，工具调用通过`ToolUseContent` | `ToolResultContent`表示。

```python
SamplingHandlerResult: TypeAlias = (str | CreateMessageResult | CreateMessageResultWithTools)
class CreateMessageResult(Result):
    role: Role
    content: SamplingContent
    model: str
    stopReason: StopReason | None = None
class CreateMessageResultWithTools(Result):
    role: Role
    content: SamplingMessageContentBlock | list[SamplingMessageContentBlock]
    model: str
    stopReason: StopReason | None = None
    @property
    def content_as_list(self) -> list[SamplingMessageContentBlock]
SamplingContent: TypeAlias = TextContent | ImageContent | AudioContent
```

FastMCP客户端SDK针对OpenAI API、Google GenAI和Anthropic Anthropic API定义了如下三个`SamplingHandler`类型。

- OpenAISamplingHandler
- GoogleGenaiSamplingHandler
- AnthropicSamplingHandler
